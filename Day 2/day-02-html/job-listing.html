MERN Stack Developer

Company: Tech Solutions Pvt. Ltd.

Location: Pune, Maharashtra

Work Mode: Hybrid

Employment Type: Full-time

Salary Range: ₹4,00,000 - ₹7,00,000 per year

Job Description

We are looking for a motivated MERN Stack Developer to develop and maintain modern web applications. The candidate will work with frontend, backend, APIs, and databases.

Responsibilities

  • Develop responsive web applications.
  • Build and maintain REST APIs.
  • Work with Node.js and Express.js.
  • Develop frontend features using React.
  • Work with MongoDB databases.
  • Debug and fix application issues.
  • Collaborate with other developers.

Required Skills

  • HTML5 and CSS3
  • JavaScript
  • React.js
  • Node.js
  • Express.js
  • MongoDB
  • REST API
  • Git and GitHub

Preferred Qualifications

  • Bachelor's degree in Computer Science or related field.
  • Knowledge of Git and GitHub.
  • Understanding of REST APIs.
  • Basic knowledge of cloud technologies.
  • Good problem-solving skills.
  • Good communication skills.
