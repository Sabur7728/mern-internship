without requiring JavaScript.

PROFESSIONAL HTML CODING STANDARDS
------------------------------------

I reviewed my CareerConnect project and followed professional HTML
coding standards.

- I use lowercase HTML element names.
- I maintain proper indentation.
- I use semantic HTML elements where appropriate.
- I use meaningful names for classes.
- I use descriptive page titles.
- I provide alt text for meaningful images.
- I use labels for form controls.
- I maintain a logical heading hierarchy.
- I keep my HTML structure readable.
- I avoid unnecessary nesting.
- I use HTML for structure and meaning rather than visual styling.

and easier for other developers to understand.
