# Practical Exercises

## 1. User Profile Program

Created a JavaScript object containing user information.

### Data Included

- Name
- Email
- Age
- City
- Role
- Skills

### Example

```javascript
const user = {
    name: "Shaikh Sabur",
    email: "sabur@example.com",
    age: 21,
    city: "Maharashtra",
    role: "MERN Developer",
    skills: ["JavaScript", "Node.js", "MongoDB"]
};

console.log(user.name);
console.log(user.email);
console.log(user.role);
console.log(user.skills[0]);
